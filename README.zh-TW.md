## 範圍說明

這是一份針對 2026 年 5 月美國 war.gov 公開釋出的 UFO/UAP Release 01 所製作的便利下載包。

- 這是一份給一般使用者下載的整理包，內容來自 war.gov 公開釋出的 UFO/UAP 檔案。

- 這不是文件分析或研究報告。

- 這不是美國政府官方網站，也不是官方授權或背書的頁面。

## 備註

這份下載包是使用 **快檔連結** 整理與交付的，目的是讓一般使用者更容易下載這批美國戰爭部公開的 UFO/UAP 檔案。
