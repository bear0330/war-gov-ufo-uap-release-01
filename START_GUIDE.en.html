How to begin browsing this archive

This release is best understood as a collection of public records, not a single report with one narrative. Start with the quick tour below, then use the filename groups and index to explore deeper.

20-minute quick tour

  1. Watch 3–5 MP4 videos.
  2. Open the 8 FBI A PNG images.
  3. Open the 6 NASA Apollo JPG images.
  4. Open western_us_event_slides_5.08.2026.pdf, 2024-04-30-composite-sketch.pdf, and usper-statement-redacted.pdf.
  5. Stop there unless you want to read deeper.

1-hour review path

  1. Watch all 28 MP4 videos.
  2. Browse all 14 images.
  3. Read the shorter modern DOW-UAP-D... PDFs.
  4. Read the FBI sighting-related PDFs.
  5. Skim the NASA transcripts/debriefings.
  6. Save the very large historical PDFs for later.

Filename groups at a glance

DOW-UAP-D...
Department of War document records, mission reports, range fouler reports, emails, or related written material.
DOW-UAP-PR...
Public release / media records. In this pack, many PR records correspond to videos.
FBI PHOTO...
FBI-related photo material and related PDFs.
NASA-UAP-D...
NASA / Apollo / Skylab transcripts or debriefing documents.
NASA-UAP-VM...
NASA visual media images.
dos-uap / 059uap...
State Department cable records.

Large number-prefixed PDFs

Files beginning with numbers such as 18_, 38_, 59_, 65_, 255_, 331_, 341_, and 342_ look like historical archival record identifiers. They are useful, but less beginner-friendly.

Using the index

The easiest way to navigate is to open files_index.csv in Excel, Google Sheets, Numbers, LibreOffice, or any spreadsheet viewer.

Useful columns include: filename, media_type, url, source_page, size_bytes, and sha256.

Important note

This pack is meant for convenience, archiving, and offline review. It does not analyze the files, does not rank their importance, and does not claim the files prove extraterrestrial life or alien technology.

For source verification, use files_index.csv, files_index.jsonl, checksum.sha256, manifest.json, and the original source page: https://www.war.gov/UFO/.
