档名群组说明

DOW-UAP-D...
通常是美国战争部的 UAP 文件纪录、任务报告、range fouler report、email 或相关文字资料。
DOW-UAP-PR...
通常是公开释出或媒体相关纪录。在这份包里，很多 PR 纪录对应到视频。
FBI PHOTO...
FBI 相关照片与对应 PDF 文件。
NASA-UAP-D...
NASA / Apollo / Skylab 的逐字稿或任务简报文件。
NASA-UAP-VM...
NASA 相关视觉影像资料。
dos-uap / 059uap...
State Department cable，也就是美国国务院电报类纪录。

数字开头的大型 PDF

像 18_、38_、59_、65_、255_、331_、341_、342_ 这类数字开头的 PDF，看起来比较像历史档案馆藏的编号。它们可能有研究价值，但对一般使用者来说比较不容易入门。

如何使用索引档

最简单的方式，是用 Excel、Google Sheets、Numbers、LibreOffice 或任何试算表工具打开 files_index.csv。

比较有用的栏位包括：filename、media_type、url、source_page、size_bytes、sha256。

重要提醒

这份包的用途是方便下载、保存与离线浏览。它不分析档案内容、不替档案重要性排序，也不主张这些档案证明外星生命或外星科技存在。

如果你想确认来源与档案完整性，可以使用 files_index.csv、files_index.jsonl、checksum.sha256、manifest.json，并比对原始来源页面：https://www.war.gov/UFO/。
